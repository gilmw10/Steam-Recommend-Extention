# Steam-Recommend-Extention

## 프로젝트 소개
`Steam-Recommend-Extention`은 Steam 플랫폼에서의 게임 추천 경험을 향상시키기 위해 개발된 브라우저 확장 프로그램입니다. 이 프로젝트는 사용자에게 보다 맞춤화되거나 추가적인 추천 관련 기능을 제공하여, 새로운 게임을 발견하는 과정을 더욱 효율적이고 즐겁게 만드는 것을 목표로 합니다. (프로젝트 설명이 제공되지 않아, 프로젝트명과 파일 목록을 기반으로 유추하여 작성되었습니다.)

## 주요 기능
*   **인터랙티브 팝업 UI**: 브라우저 툴바에서 확장 프로그램 아이콘을 클릭하여 접근할 수 있는 사용자 친화적인 팝업 인터페이스를 제공합니다. ( `popup.html`, `popup.css`, `popup.js`를 통해 유추)
*   **백그라운드 처리**: Steam 웹 페이지와의 상호작용 또는 데이터 관리를 위한 백그라운드 로직을 수행합니다. ( `background.js`를 통해 유추)
*   **맞춤형 추천**: Steam의 기존 추천 시스템을 보완하거나, 새로운 기준에 따른 게임 추천을 제공할 수 있습니다. (프로젝트명 "Recommend"를 통해 유추)
*   **빠른 설정 및 정보 접근**: 팝업을 통해 추천 관련 설정이나 추가 정보를 쉽고 빠르게 확인할 수 있는 기능을 제공할 가능성이 있습니다.

## 기술 스택
이 프로젝트는 웹 확장 프로그램 개발에 필수적인 표준 웹 기술을 활용합니다.
*   **JavaScript**: 확장 프로그램의 핵심 로직과 동적인 기능을 구현합니다.
*   **HTML**: 팝업(popup) 사용자 인터페이스의 구조를 정의합니다.
*   **CSS**: 팝업(popup) 사용자 인터페이스의 스타일링을 담당합니다.
*   **Web Extension API**: 브라우저 확장 프로그램의 기능을 구현하기 위한 API를 활용합니다. (예: Chrome Extension API, Manifest V3 등)

## 설치 방법
이 확장 프로그램은 개발자 모드를 통해 브라우저에 로드할 수 있습니다. 현재 Chrome 또는 Chromium 기반 브라우저를 기준으로 설명합니다.

1.  **리포지토리 클론**:
    ```bash
    git clone [이곳에 프로젝트의 GitHub URL을 입력하세요. (예: https://github.com/your-username/Steam-Recommend-Extention.git)]
    cd Steam-Recommend-Extention
    ```
2.  **브라우저 확장 프로그램 관리 페이지 열기**:
    *   Google Chrome: 브라우저 주소창에 `chrome://extensions`를 입력하고 Enter를 누릅니다.
    *   Microsoft Edge: 브라우저 주소창에 `edge://extensions`를 입력하고 Enter를 누릅니다.
3.  **개발자 모드 활성화**:
    *   페이지 우측 상단 또는 좌측에 있는 "개발자 모드" 토글 스위치를 켜서 활성화합니다.
4.  **압축 해제된 확장 프로그램 로드**:
    *   "압축 해제된 확장 프로그램을 로드합니다" 또는 "Load unpacked" 버튼을 클릭합니다.
    *   클론한 `Steam-Recommend-Extention` 프로젝트 폴더를 선택하고 "폴더 선택"을 클릭합니다.

이제 확장 프로그램이 브라우저에 설치되어 툴바에 아이콘이 나타날 것입니다.

## 실행 방법
확장 프로그램이 설치되면 다음 단계를 따릅니다.

1.  **확장 프로그램 아이콘 클릭**: 브라우저 툴바에 새로 추가된 `Steam-Recommend-Extention` 아이콘을 클릭합니다. 이 아이콘을 클릭하면 확장 프로그램의 팝업 UI가 열립니다.
2.  **Steam 페이지 방문**: Steam 웹사이트 (예: Steam 상점 페이지, 탐색 목록 등)를 방문하여 확장 프로그램이 제공하는 새로운 추천 기능이나 정보 변화를 확인합니다.
3.  **팝업 UI 활용**: 팝업 UI를 통해 추천 설정 조정, 추가 정보 조회 등 확장 프로그램이 제공하는 기능을 활용합니다.

## 프로젝트 구조
프로젝트는 웹 확장 프로그램의 표준적인 파일 구조를 따릅니다.

```
Steam-Recommend-Extention/
├── background.js       # 백그라운드에서 실행되는 스크립트. 확장 프로그램의 핵심 로직 및 이벤트 리스너를 포함합니다.
├── manifest.json       # 확장 프로그램의 메타데이터(이름, 버전, 권한 등)와 구성 정보를 정의합니다.
├── popup.css           # 팝업 HTML 파일의 스타일을 정의하는 CSS 파일입니다.
├── popup.html          # 확장 프로그램 아이콘 클릭 시 표시되는 팝업 UI의 HTML 구조를 정의합니다.
└── popup.js            # 팝업 HTML과 상호작용하는 JavaScript 로직을 포함합니다.
```
